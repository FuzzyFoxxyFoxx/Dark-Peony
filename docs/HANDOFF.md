## Как работаем (важно)
1. **Каждая правка → коммит и пуш в `main`**:
   `git add … && git commit -m "…" && git pull -q --rebase --autostash origin main && git push -q origin HEAD:main`.
   В конце сообщения коммита: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. `.DS_Store` не коммитить.
   Пуш работает через `gh` (авторизован в браузере автора).
2. **Проверка глазами — через Chrome (MCP `chrome-devtools`)**, страница pageId 2. Кадры конкретного момента:
   `index.html?figure=jellyfish&manual`, затем `DP.morphTo('peony'); DP.debug.step(сек)`; кадр WebGL копировать
   в 2D-canvas сразу после `step` и возвращать `toDataURL` через `evaluate_script` с `filePath`
   `…/Dark-Peony/.sheet0.json` (папка scratchpad для MCP недоступна) → python-декод в scratchpad → удалить json.
   Автор просит **плотные раскадровки** (16–36 кадров через 0.1–0.2 с) — по редким кадрам ошибки движения не видны.
3. **После каждого изменения оставлять в Chrome живую страницу** (не `?manual`!) и выводить её вперёд
   (`select_page bringToFront`): `index.html?figure=jellyfish&debug&tune` — панель ползунков + цикл морфинга
   (`&loop=0` — без цикла). Автор смотрит это окно вместо обновления Safari.
4. Большие изменения — сначала обсудить; «тяжёлые» решения (новый GPGPU и т. п.) — только с согласия автора.
5. «Сохрани/запомни» → версия в `versions/ГГГГ-ММ-ДД_ЧЧ-ММ_имя/` (время Амстердама), git-тег, запись в
   `versions/README.md`, ссылка автору (подробно — `CLAUDE.md` §3).
6. Честно сообщать, что проверено, а что нет (например, iPhone проверяет только автор).

## Что сделано к этой точке
- **Фигуры:** пион (`js/figures/peony.js`, утверждён), медуза (`js/figures/jellyfish.js`, утверждена целиком:
  купол, юбка, ленты с рюшами-Безье, 12 щупалец 9+3 с кольцами поперёк нити, тычинки).
- **Морфинг** (`js/core/morph.js`, `smokesim.js`, `orchestrator.js`): режим по умолчанию **`disk`** — «чистый вихрь»
  на видеокарте: распад от краёв к центру и низу с закруткой, вихрь «как чай в чашке», уровни 1 («торнадо»: верх →
  верх, низ → низ), завихрения Квана (водовороты двух масштабов) + самозатенение, сборка по спирали сверху вниз,
  ≈3.5 с. Вращение фигуры при морфинге (раскрутка/докрутка по инерции, `figureSpin`), «эхо» наклона сцены.
  Прочие режимы сохранены для отката: `sphere`, `sweep`, `smoke`, `fountain`, `vortex`.
- **Плавность:** подготовка перехода заранее в простое (Web Worker + requestIdleCallback + загрузка полосами),
  запас экземпляров фигур, постепенный сброс нагрузки, `gl.finish` на переходах — рывков в начале/конце нет.
- **Панель `?tune`** (`js/core/tune.js`): цикл, замедление, выбор режима, ползунки всех параметров (пути в
  `DP.config.morph`; с «@» — от `DP.config`: фон), «ссылка с настройками» (`m.<путь>=` в адресе).
- **Лаборатория дымного кольца:** `lab/smoke.html` (1 млн частиц, ползунки).
- **Фон** (`js/core/stage.js`, `DP.config.hud` / `DP.config.background`): две «весики» кругов (малая — крестики,
  масштабируются; большая ×2.0), галактика: спиральная туманность в плоскости «пола» (процедурная текстура),
  звёзды диска на рукавах, «небо» (дальняя сфера, параллакс), облака дыма, защитный кокон (перед фигурой фона нет),
  звёзды вдвое меньше прежнего. **Последнее (не оценено автором):** плоскость галактики наклонена так, чтобы горизонт
  был на 1/4 высоты экрана сверху (`background.horizon` 0.25).
- **Документы:** `docs/NODES.md` — бриф автора про ноды `[Я] [Смысл] [Код] [Форма]` + переосмысление + техплан

## Где остановились / что дальше (2026-09-25, вечер)
1. **Фон готов на сегодня** (оценён автором по ходу): спиральная галактика — 5 неравных рукавов, мягкая туманность
   без «царапин» (`nebulaAlpha` 0.3 — фигуры важнее фона), звёздная пыль вдоль рукавов с толщиной (`dustSize` 1.5,
   распыление `dustSpread` 1.3, яркость ±50%), кокон не действует на рукава; дальний край диска на 1/4 экрана сверху;
   крестики HUD тоньше/меньше/прозрачнее. Эксперимент «медуза с наклоном как у пиона» — отклонён, откат.
2. **Завтра — новая фигура.** Варианты автора и оценка сложности (от простого к сложному):
   - **Светило с протуберанцами + орбиты со спутниками** (рекомендовано первым): шар из точек с френелем, как купол
     медузы; протуберанцы — частицы, убегающие от поверхности радиально и арками; орбиты — кольца точек, спутники —
     маленькие шары. Всё из простых примитивов, движение в шейдере.
   - **Око Саурона**: шар со зрачком-щелью, частицы по спирали затягиваются в зрачок, как в чёрную дыру. Тоже просто,
     опыт вихря из морфинга пригодится.
   - **Ромбический кристалл + цепи по вытянутым орбитам + круги с рунами**: кристалл и цепи несложны (звенья — кольца,
     как у щупалец), руны требуют отдельного рисунка знаков.
   - **Нейросетевое облако** (узлы + связи-синапсы, бегущие импульсы): средне — нужны линии из точек.
   - **Дерево с корнями** (толстый ствол, ветвистая крона): ветвление, много подбора, чтобы было красиво.
   - **Условный человек из кривых Безье**: сложнее всего — пропорции и силуэт, много итераций с автором.
     Референс автора — `docs/refs/human-bust.png` (размытый зелёный бюст): минимум деталей, но читаются глазные впадины,
     скулы, нос, брови, уши; изгибы плавно уходят на нет. Автор считает это реалистичным. План: силуэт и профиль —
     кривые Безье (вид спереди и сбоку), по ним «натягивается» поверхность головы и плеч; черты лица — мягкие выпуклости
     и впадины поверх (гладкие поля, без резких краёв); точки ложатся на поверхность рядками, френель показывает рельеф.
     Вид «размытого свечения» близок к нашему точечному стилю. Делать последним или когда автор решит.
