### «Компьютерное зрение» — посмотреть свежим взглядом
*Добавлено: 2026-09-26*

Модуль `js/core/vision.js` в целом устраивает автора (версия `2026-09-26_19-48_vision-ascii` + облегание пятна).
Не решено / проверить:
- Стиль линий: автор ещё не выбрал между `lineStyle` 0 / 1 / 2 (по умолчанию 2 — голубой волосок).
- На медузе крупные рамки иногда охватывают большие куски купола — возможно, ограничить максимум или поднять порог.
- Рамки с символами иногда встают на край фигуры (много пустоты) — возможно, выбирать самое заполненное место.
- У пиона и медузы рамки в режиме «по точкам» (`track` 0) стоят на точках в покое, без анимации качания.
- iPhone не проверен: чтение уменьшенного кадра 12 раз/с; при проблеме — `track` 0 или реже.
- Доли цепких/нервных рамок, частота всплесков и пропаданий — подобрать по ощущению.

### Единый темп и «вес» всех фигур
*Добавлено: 2026-09-24*

Все фигуры должны быть одного рода: по скорости анимации, по визуальному весу (видимой массе)
и по виду. Никто не может быть заметно быстрее или медленнее остальных.

- Юбка медузы, возможно, чуть быстрее, чем анимация пиона. Сейчас её ритм — пульсация купола
  (`uTime * 1.1`, цикл ≈ 5.7 с), рюши бегут по кругу со скоростью 0.35 рад/с.
- Что сделать: визуально сравнить пион и медузу (плотные раскадровки рядом) и сравнить в коде
  частоты анимаций: у лепестков пиона `uTime * 0.85 / 0.62 / 1.1`, у щупалец `1.2 / 0.9`;
  у медузы — купол `1.1`, юбка `1.1 / 1.3 / 0.8`, ленты `0.8–1.1`, щупальца `1.2 / 0.9`.
  Свести к общей шкале (например, общий множитель темпа фигуры в `DP.config`).
- Решено автором: вернуться в конце, после доводки медузы по частям.
